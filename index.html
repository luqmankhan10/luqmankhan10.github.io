Document Q&A Chatbot (RAG)

shipped

LangChain · Gemini · Streamlit · FAISS

A retrieval-augmented chatbot that answers questions over a set of PDF documents instead of relying on the model's memory. A person uploads documents, asks a question in plain language, and gets an answer with the source passages it was drawn from — so the reasoning stays checkable.

PDF upload→ chunking & embeddings→ vector store→ retrieval→ Gemini generation→ cited answer

Built end to end: the LangChain pipeline handles ingestion, embedding, and retrieval; Gemini generates the final answer constrained to the retrieved chunks; Streamlit provides the interface a non-technical user interacts with. Put together as a fast, working portfolio piece rather than a long-running product.
